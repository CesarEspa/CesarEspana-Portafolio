02 · Sobre mí

Constructor por vocación, metódico por formación.

De la selva amazónica colombiana a APIs en producción — el código siempre ha sido el lenguaje.

Me formé como Ingeniero en Sistemas en la Universidad de la Amazonia y desde 2024 construyo aplicaciones web completas para clientes reales. Trabajo con Java Spring Boot, Node.js y .NET en el backend; MySQL y SQL Server en la capa de datos; y Angular o interfaces web en el frontend.

Lo que me mueve: escribir código que funcione en producción, no solo en local. Diseño APIs que escalan, estructuro bases de datos sin redundancias y construyo interfaces que tienen sentido para quien las usa — no solo para quien las construye.

Cuando no estoy codificando, estoy aprendiendo — un bootcamp Full-Stack Java, una maestría en IA y un máster en Data Science, todos a la vez. Creo que el mejor desarrollador hoy combina ingeniería sólida, comprensión de datos y criterio de producto.
